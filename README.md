# Education Career Advisor

## Project Overview

Education Career Advisor is a Django-based web application developed to help students explore suitable career options and make better education-related decisions.

The system provides information about careers, courses, colleges, and scholarships in one place.

## Features

* Student Registration and Login
* Career Information
* Course Information
* College Information
* Scholarship Information
* Career Recommendations
* Admin Panel for managing data
* User-friendly web interface

## Technologies Used

* **Frontend:** HTML, CSS, JavaScript
* **Backend:** Python, Django
* **Database:** SQLite
* **Tools:** VS Code

## Career Information

The system provides career details such as:

* Career Title
* Description
* Required Skills
* Minimum Marks

Some career options include:

* Software Developer
* Web Developer
* Data Scientist
* Data Analyst
* Cyber Security Analyst
* Cloud Engineer
* AI/ML Engineer
* Database Administrator

## Purpose

The main purpose of this project is to provide students with useful career and education information and help them choose suitable career paths according to their interests and academic background.

## How to Run the Project

1. Install Python.
2. Install Django:

```bash
python -m pip install django
```

3. Open the project folder in VS Code.
4. Run the following command:

```bash
python manage.py runserver
```

5. Open the following URL in your browser:

```text
http://127.0.0.1:8000/
```

## Admin Panel

The Django admin panel can be accessed using:

```text
http://127.0.0.1:8000/admin/
```
